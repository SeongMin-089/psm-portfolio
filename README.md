# PSM Portfolio

개인 프로젝트와 팀 프로젝트, 개발 경험을 정리한 웹 포트폴리오입니다.

React를 기반으로 제작했으며, 프로젝트 소개와 기술 스택, 미니 프로젝트, 연락처 등을 한 페이지에서 확인할 수 있도록 구성했습니다.

## 🔗 Portfolio

**Live Demo**
https://psm-portfolio-ct84.vercel.app/

## ✨ Features

* 반응형 웹 디자인
* Dark / Light 테마 지원
* Framer Motion 기반 스크롤 애니메이션
* 프로젝트 및 미니 프로젝트 소개
* 프로젝트별 Demo / GitHub 링크 제공
* 관리자 페이지를 통한 게시물 관리
* Formspree를 활용한 Contact Form
* Three.js 기반 3D 인터랙션

## 📂 Main Sections

### Hero

포트폴리오의 첫 화면으로 간단한 소개와 주요 인터랙션을 제공합니다.

### Skills

프로젝트와 학습 과정에서 사용한 Frontend, Backend, Database, Tool 관련 기술을 정리했습니다.

### Projects

주요 프로젝트의 역할, 사용 기술과 구현 내용을 소개합니다.

* **CoolRoute**
  콜드체인 물류 기업을 컨셉으로 제작한 팀 프로젝트
  React와 TypeScript를 기반으로 기업 랜딩 페이지와 점주·배송기사·물류센터별 대시보드를 구현했습니다.

* **Octalog**
  UFC 파이터 기록을 컨셉으로 제작한 Full Stack CRUD 프로젝트
  React, Spring Boot, MySQL을 기반으로 JWT 인증, AWS S3 이미지 업로드, Docker 배포를 구현했습니다.

* **Wifi Spot**
  공공 와이파이 데이터를 Kakao Map을 통해 시각화하고 즐겨찾기로 관리할 수 있는 React 프로젝트입니다.

* **Diptyque UI Clone**
  Diptyque 웹사이트의 레이아웃과 UI를 분석하여 React와 SCSS 기반으로 구현한 반응형 UI 프로젝트입니다.

* **CafeIndex**
  Naver API를 활용해 카페 게시글을 검색하고 MongoDB에 즐겨찾기를 관리할 수 있도록 제작한 FastAPI 기반 프로젝트입니다.

### Mini Projects

학습 과정에서 제작한 다양한 미니 프로젝트를 정리했습니다.

### Contact

포트폴리오 방문자가 간단하게 메시지를 전달할 수 있도록 Contact Form을 제공합니다.

## ⚙️ Getting Started

```bash
# Repository Clone
git clone https://github.com/SeongMin-089/psm-portfolio.git

# Directory
cd psm-portfolio

# Install
npm install

# Development Server
npm run dev
```

## 📦 Build

```bash
npm run build
```
